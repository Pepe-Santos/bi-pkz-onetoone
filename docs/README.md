# Documentação

**Branch:** `documentacao` · **Responsáveis:** Gerência (Lucas e Pedro)

Registro do que foi decidido e de como o projeto funciona, para que qualquer pessoa da equipe consiga se integrar.

## Escopo

- Decisões (`AQ`, `DEC`) com data, motivo e quem decidiu.
- Riscos (`RIS`) e mitigação.
- Atas das reuniões com o cliente e entre frentes.
- Diagramas de arquitetura e guias de uso (como rodar, como gerar um relatório).
- Atualização do README principal conforme o projeto avança.

## Estrutura sugerida

```
docs/
├── decisoes/    # uma página por decisão
├── riscos/
├── atas/
└── arquitetura/
```

## Regras

- A documentação geral (`DOC-PKZ-OTO-001`) é confidencial e **não** entra aqui — só resumos sem dados do cliente.
- Achados de segurança do banco do cliente ficam nos canais internos.
